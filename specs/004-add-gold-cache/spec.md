# Feature Specification: ゴールド・キャッシュによる採掘777倍

**Feature Branch**: `main`（ブランチ作成フックなし）

**Created**: 2026-10-03

**Status**: Draft

**Input**: User description: "すでに採掘７倍にするクローム・キャッシュは実装されているが、採掘を777倍にするゴールド・キャッシュを実装して。"

## Clarifications

### Session 2026-10-03

- Q: ゴールド・キャッシュの出現方法は、既存キャッシュの出現時に10%の確率でゴールドへ置き換える方式にしますか? → A: 既存の出現機会を共有し、ゴールド10%・クローム90%とする。ゴールド出現時は専用の特別なアイコン（スプライト）を使用する。

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 回収して採掘を加速する (Priority: P1)

プレイヤーはゴールド・キャッシュを回収して、短時間の手動採掘で大量の資源を得る。

**Why this priority**: 採掘777倍という要求の中心であり、回収機会を活用する楽しさを提供する。

**Independent Test**: 同じ装備・設備の条件で、回収前後の1回の採掘獲得量を比較する。

**Acceptance Scenarios**:

1. **Given** 通常の採掘獲得量が B、**When** ゴールドを回収して20秒以内に採掘する、**Then** 獲得量は B × 777 となり、マウスと既存のキーボード採掘で一致する。
2. **Given** ゴールド効果中、**When** 回収から20秒が経過する、**Then** その時点の通常採掘量に戻る。
3. **Given** ゴールド効果中、**When** 自動生産またはオフライン収益を得る、**Then** 777倍は適用されない。
4. **Given** ゴールドが出現中、**When** 回収せず10秒が経過する、**Then** 消滅し、資源・倍率は変化しない。

---

### User Story 2 - 種類と有効時間を把握する (Priority: P2)

プレイヤーはゴールドをクロームと見分け、回収後は現在の倍率と残り時間を確認できる。

**Why this priority**: 希少な機会を認識し、効果中に採掘する判断につながる。

**Independent Test**: 両種類の出現画面、回収直後、効果中、終了後を確認する。

**Acceptance Scenarios**:

1. **Given** ゴールドが出現する、**When** 画面を確認する、**Then** クロームとは絵柄の異なるゴールド専用の金色アイコン（スプライト）と種類表示で区別でき、主要な採掘・購入操作を妨げない。
2. **Given** ゴールドを回収する、**When** 効果が始まる、**Then** ゴールド由来の777倍と20秒の持続時間を通知し、効果中は倍率と残り秒数を表示する。
3. **Given** 効果終了時刻を迎える、**When** 画面が更新される、**Then** 777倍を有効な効果として表示しなくなる。

---

### User Story 3 - 既存報酬と進行を維持する (Priority: P2)

プレイヤーは既存のクローム報酬を引き続き得られ、効果の競合や再開によって進行を失わない。

**Why this priority**: 意図しない倍率の掛け算や既存報酬の退行を防ぐ。

**Independent Test**: 両倍率の取得順、重複取得、再読み込み、既存セーブを確認する。

**Acceptance Scenarios**:

1. **Given** クロームが出現中、**When** 回収する、**Then** 従来の即時資源報酬または20秒の採掘7倍を各50%で得る。
2. **Given** 7倍効果中、**When** ゴールドを回収する、**Then** 777倍に置換し、回収から20秒間有効になる。
3. **Given** 777倍効果中、**When** クロームの7倍報酬を得る、**Then** 777倍の倍率・終了時刻を維持し、7倍を予約しない。777倍終了後は通常倍率に戻る。
4. **Given** 777倍効果中、**When** 別のゴールドを回収する、**Then** 倍率を維持し、最後の回収から20秒後まで有効になる。
5. **Given** 効果中に獲得した資源を保存済み、**When** 再読み込みする、**Then** 保存済み資源・設備・装備を保持し、一時効果を復元しない。

### Edge Cases

- 自動生産がゼロでも通常の手動採掘量に777倍を適用する。
- 効果中の装備強化・設備購入は、その後の通常採掘量に反映してから777倍を適用する。
- 砂嵐併用時も既存の通常採掘量の計算を維持し、その結果に777倍を一度だけ適用する。
- 同じキャッシュへの連続操作では回収を一度だけ成立させる。
- 消滅時刻ちょうど以降の回収は無効、効果終了時刻ちょうど以降の採掘は通常倍率とする。
- 画面非表示から戻った場合も実際の経過時間で効果を終了し、非表示によって延長しない。
- タイトル・勝利画面から採掘画面へ入り直す際と新規ランでは一時効果を解除する。継続ランの資源は保持する。
- 777倍効果中のクローム即時報酬は従来の算定方法を維持し、777倍しない。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 出現機会ごとにゴールド10%、クローム90%で種類を選ぶ。両種類を合わせて画面上に最大1個だけ出現させる。
- **FR-002**: 初回出現まで17.5〜35秒、以後は回収・消滅から35〜70秒で次を出現させる。両種類とも未回収なら出現から10秒で消滅する。
- **FR-003**: ゴールド回収は必ず20秒間の手動採掘777倍を付与する。即時報酬との抽選を設けない。
- **FR-004**: 777倍はその時点の装備・設備と既存ルールによる通常の採掘量に適用する。マウス・既存キーボード操作で一致させ、自動生産・オフライン収益には適用しない。
- **FR-005**: 7倍と777倍は乗算・加算せず、強い倍率を優先する。取得順・同倍率再取得の処理はストーリー3の条件に従う。
- **FR-006**: 出現時にクロームとは絵柄の異なるゴールド専用の金色アイコン（スプライト）を使用し、種類表示と合わせて識別可能にする。クロームの色変更だけではこの要件を満たさない。さらに、回収時の通知、効果中の倍率・残り秒数表示、終了時の有効表示解除を行う。
- **FR-007**: 未回収消滅、二重回収、期限境界、非表示からの復帰は Edge Cases の一度だけの回収と時間規則に従う。
- **FR-008**: クロームの各50%の報酬抽選、即時報酬算定、20秒の7倍効果を維持する。777倍との競合時は FR-005 を優先する。
- **FR-009**: 既存セーブの保存済み資源・設備・装備を保持して読み込めること。一時効果は保存から復元せず、採掘画面への入り直し・新規ランで解除する。
- **FR-010**: ゴールドの音にも既存の音量・ミュート設定を反映する。ミュート時に回収しても音を鳴らさず、視覚通知は表示する。

### Key Entities

- **キャッシュ**: 種類、位置、有効期限、回収状態を持つ一時的な報酬機会。
- **採掘倍率効果**: 7倍または777倍の倍率と終了時刻を持つ。同時に有効な効果は1つ。
- **ランの進行**: 資源、累計獲得量、設備、装備。効果中に得た資源も通常の進行として扱う。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 同一条件で、効果中のマウス・キーボード採掘獲得量が通常の777倍となり、終了時刻以降は通常倍率となる。
- **SC-002**: 回収、未回収消滅、両倍率の取得順、重複取得、再読み込みの受け入れ条件をすべて満たし、重複報酬・倍率の積み重ねが0件である。
- **SC-003**: ゴールド効果の有無だけが異なる同一条件で、自動生産・オフライン収益の差が0であり、既存セーブの進行欠落が0件である。
- **SC-004**: ゴールドはクロームとは絵柄の異なる専用アイコンと種類表示で識別でき、効果中の777倍と残り秒数を画面内で確認できる。終了後に有効表示が残る件数は0件である。

## Assumptions

- 「採掘777倍」は既存の採掘7倍と同じ手動採掘を対象と解釈する。
- 未指定の効果時間は20秒とする。ゴールド10%・クローム90%で既存の出現機会を共有する方式はユーザー確認済み。
- 競合では強い倍率を優先し、弱い効果の予約・復帰は行わない。
- 既存の出現、採掘、クローム報酬、進行保存、音声設定を前提とする。
- 新たな購入商品、実績、永続倍率、オフラインイベント、既存ゲーム内表示全体の翻訳は対象外とする。
