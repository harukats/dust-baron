# 操作・表示契約

## 出現と回収

既存の出現機会を共有しgold10%、chrome90%。対象は最大1個、寿命10秒。通常画面では最長辺96pxで、既存の鉱床左右の空き地へ表示する。goldは専用画像と `GOLD CACHE`、chromeは既存画像と `CHROME CACHE` を表示する。ラベルは回収・消滅で同時に消える。クリックは対象の表示範囲内で受け付ける。透明余白の大きい画像は合格にしない。

回収直前に期限を確認し、期限ちょうど以降は報酬なし。同一対象の二度目の操作も報酬なし。goldは必ず777倍を開始する。chromeの即時報酬・7倍抽選は各50%。

## 採掘と通知

gold回収通知は `GOLD FRENZY!` と `digging x777 for 20s` を基本とし、既存英語UIのまま使用する。効果中HUDは `FRENZY x777 Ns`（7倍なら `FRENZY x7 Ns`）と、その時点の実際の採掘獲得量を表示する。Nは残秒数の切り上げ。期限終了時は次の描画で有効表示を解除する。

通知・HUD・鉱床の既存発光・獲得量の文字色はgoldに対応する明るい金色を使う。既存COLOR.goldは暗いプレート色のため読みやすい色をconfigに別途定義する。777中に7倍を引いた場合は777を維持した旨を通知し、7倍が開始したと誤表示しない。

マウスとSPACEは同一の採掘結果。既存のキーリピート抑止を維持する。自動生産、オフライン、chrome即時報酬に777倍を掛けない。効果音は既存cache/chimeを再利用してsoundのミュートと音量を守る。

## 継続・解除・画面サイズ

非表示でも効果・未回収寿命の絶対期限は進む。画面再入場・新規ラン・保存の再読込では効果を解除する。保存済み進行は保つ。1280×720と960×540で、画像・種類ラベル・採掘HUD・ショップの主要操作が画面内に収まること。

FR-001〜010との対応、状態遷移、生成条件は [仕様](../spec.md)、[データモデル](../data-model.md)、[アセット契約](gold-cache-asset.md) を参照する。
