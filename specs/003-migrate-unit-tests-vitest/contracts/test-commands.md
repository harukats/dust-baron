# コマンド契約: ユニットテスト

開発者と CI が利用するコマンドの外部から見える振る舞いを定義する。

| コマンド | 対象 | 成功条件 | 失敗条件 |
|----------|------|----------|----------|
| `pnpm test` | `src/**/*.test.ts` の全ユニットテスト | 全件合格し、1回で終了 | 1件以上失敗、または対象0件 |
| `pnpm test src/economy.test.ts` | 指定ファイル | そのファイルの全テストが合格 | 該当ファイルなし、または失敗 |
| `pnpm test src/economy.test.ts -t costs` | 指定ファイル内の一致する名前 | 一致したテストがすべて合格 | 一致0件、または失敗 |
| `pnpm build` | 型検査→全ユニットテスト→Web 出力 | 各段階が成功 | 型検査・ユニットテスト・出力のいずれかが失敗 |
| `pnpm test:e2e` | Playwright のブラウザ操作テスト | 専用コマンドの既存条件 | 専用コマンドの既存条件 |

`pnpm test` の出力は失敗したテスト名と理由を示す。名前指定で全件 skipped となった場合も実行0件として失敗する。E2E テストは標準ユニットテストコマンドの探索対象に含めない。CI の `test` ジョブは既存どおり `pnpm typecheck` と `pnpm test` を実行する。
