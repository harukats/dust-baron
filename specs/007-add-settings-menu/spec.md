# 機能仕様書: Settings画面の追加

**作業ブランチ**: `007-add-settings-menu`
**作成日**: 2026-10-15
**状態**: ドラフト（仕様品質検証済み）
**入力**: SOUNDボタンをSettingsボタンに変更し、BGMと効果音それぞれのON/OFF、全画面表示、いつでもタイトルへ戻る操作を提供する。

## ユーザーシナリオとテスト

### ユーザーストーリー1 - SettingsからBGMと効果音を変更する (優先度: P1)

プレイヤーはSettingsから音楽と効果音の状態を確認して個別に切り替え、元の画面へ戻れる。

**優先度の理由**: 既存のSOUNDに代わる入口と音楽・効果音設定という主要要求を満たす。
**独立したテスト**: タイトルからSettingsを開き、BGMと効果音を別々に切り替えて閉じることで確認できる。

**受け入れシナリオ**:

1. **前提** タイトル、採掘、Reign、実績、Victoryのいずれかを表示中、**操作** Settingsを押す、**結果** BGM、効果音、全画面表示、タイトルへ戻る、閉じるの5操作が表示される。
2. **前提** BGMがON、**操作** OFFへ切り替える、**結果** 音楽が止まりOFF表示になる。効果音の設定は変わらない。
3. **前提** BGMがOFF、**操作** ONへ切り替える、**結果** 再生が許可され次第、音楽が一重に再生されON表示になる。
4. **前提** BGMと効果音を変更済み、**操作** 画面遷移またはゲーム再起動を行う、**結果** 保存可能な環境では選択が維持される。
5. **前提** 任意の対象画面からSettingsを開いた、**操作** 閉じるかEscapeを押す、**結果** 元の画面に戻り、背後の開始・購入・転生などは実行されない。ただし、環境がEscapeを全画面解除に使用してSettingsが残った場合は、もう一度EscapeまたはCLOSEで閉じられる。

6. **前提** 効果音がON、**操作** 効果音をOFFにして採掘や購入を行う、**結果** 効果音が鳴らずOFF表示になり、BGMの選択と再生状態は変わらない。
7. **前提** 効果音がOFF、**操作** 効果音をONにして採掘や購入を行う、**結果** 再生が許可された環境では効果音が鳴り、ON表示になる。BGMの選択は変わらない。
8. **前提** 音声設定を個別に変更できる、**操作** BGMと効果音のON/ON、ON/OFF、OFF/ON、OFF/OFFを順に選ぶ、**結果** 4通りすべてで表示と実際の再生対象が一致する。

### ユーザーストーリー2 - 全画面表示を切り替える (優先度: P1)

プレイヤーはSettingsから全画面表示へ移り、通常表示へ戻せる。

**優先度の理由**: プレイ環境に合わせた表示変更という主要要求を満たす。
**独立したテスト**: Settingsから全画面への移行と解除を確認できる。

**受け入れシナリオ**:

1. **前提** 対応環境で通常表示中、**操作** 全画面表示をONにする、**結果** 全画面になり表示もONになる。
2. **前提** 全画面表示中、**操作** SettingsでOFFにする、**結果** 通常表示へ戻り表示もOFFになる。
3. **前提** 全画面表示中、**操作** 環境側の操作で解除する、**結果** Settingsの表示が実際の状態と一致する。環境がEscapeを全画面解除に使用してSettingsが残った場合は、もう一度EscapeまたはCLOSEで閉じられ、背後の操作は実行されない。
4. **前提** 非対応または切り替えが拒否される環境、**操作** 項目を確認または切り替えを試みる、**結果** 利用不可または失敗が分かり、誤ってON表示せず、他の操作を継続できる。
5. **前提** 表示モードを変更した、**操作** 設定やゲームを操作する、**結果** 主要操作部が欠けず、表示位置で操作できる。

### ユーザーストーリー3 - 進行を保持してタイトルへ戻る (優先度: P1)

プレイヤーはどの対象画面からでもSettings経由でタイトルへ戻り、CONTINUEで同じランを継続できる。

**優先度の理由**: 進行を失わずタイトルへ戻る主要要求を満たす。
**独立したテスト**: 進行のあるランからタイトルへ戻り、CONTINUE前後の進行を比較する。

**受け入れシナリオ**:

1. **前提** 採掘、Reign、実績、VictoryからSettingsを開いた、**操作** タイトルへ戻るを選ぶ、**結果** Settingsが閉じてタイトルが表示され、ランのリセットや転生は起きない。
2. **前提** 進行のあるランからタイトルへ戻った、**操作** CONTINUEする、**結果** 資源、設備、王冠、転生関連の進行、実績を保持し、経過時間の収益を重複加算しない。
3. **前提** タイトルからSettingsを開いた、**操作** タイトルへ戻るを選ぶ、**結果** Settingsが閉じ、タイトルに留まり、新しいランを開始しない。
4. **前提** 保存不可の一時プレイ中、**操作** タイトル復帰後にCONTINUEする、**結果** 同じ起動中の進行を保持し、永続保存できたと誤案内しない。

### 境界ケース

- Settingsの開閉とタイトル復帰を10回繰り返しても、入力・音楽・画面遷移が重複しない。
- Settings表示中のクリック、Space、Enter、M、Escapeで背後の開始・採掘・購入・転生・遷移が起きない。
- BGMと効果音の一方をOFFにしても、もう一方の選択と再生可否は変わらない。
- 音楽の再生許可待ちでOFFにした場合、許可後も勝手に再生しない。
- 設定保存や全画面の切り替えに失敗しても、閉じる操作やタイトル復帰ができる。
- 新規プレイ前と最終王冠取得後にもSettingsを使える。

## 要件

### 機能要件

- **FR-001**: 既存のSOUNDボタンをすべて`SETTINGS`に置き換え、タイトル、採掘、Reign、実績、Victoryから同じ設定項目にアクセス可能にする。
- **FR-002**: SettingsはBGMのON/OFF、効果音のON/OFF、全画面表示のON/OFF、タイトルへ戻る、閉じるの5操作を提供する。
- **FR-003**: BGM変更は音楽のみに適用し、現在の選択を表示する。画面遷移後も選択を保持し、保存可能な環境では再起動後も保持する。
- **FR-004**: 既存の音声設定のON/OFFを初回のBGM設定と効果音設定の両方に引き継ぐ。既存設定がない場合は両方ONにする。以降はそれぞれ独立して変更・保存する。
- **FR-005**: 音楽の重複再生を防ぎ、再生許可待ちでも最新のBGM選択を反映する。
- **FR-006**: 対応環境ではSettingsから全画面への移行と解除ができ、環境側からの解除も含め実際の状態を表示する。
- **FR-007**: 全画面非対応時は利用不可と分かる表示にする。要求失敗時は変更できなかったことを伝え、実際の状態を維持して他の操作を継続可能にする。
- **FR-008**: 閉じるまたはEscapeで開いた元の画面へ戻り、進行を維持する。ただし、環境がEscapeを全画面解除に使用した場合は解除を優先し、Settingsが残った場合はもう一度EscapeまたはCLOSEで閉じられるようにする。Settings表示中と閉じる操作時は背後の操作入力を遮断する。
- **FR-009**: タイトルへ戻る操作はタイトル自体を含む全対象画面で利用でき、進行条件や別のゲーム内操作を要求しない。
- **FR-010**: タイトル復帰では同じランと実績を保持し、保存可能な環境ではその時点の進行を保存する。CONTINUEで初期化や収益の二重加算を起こさない。
- **FR-011**: 保存不可でも設定変更、Settings開閉、タイトル復帰、同じ起動中のラン継続を可能にする。選択したBGM設定と効果音設定はその起動中に保持する。
- **FR-012**: 表示切り替え後も縦横比を維持し、主要操作部が表示範囲に収まり、表示位置と入力位置を一致させる。
- **FR-013**: 開閉を繰り返しても一度の入力による重複実行や、閉じたSettingsへの入力が起きない。

- **FR-014**: 効果音のON/OFFをBGMとは独立して変更し、現在の選択を表示する。OFF時は操作音やイベント音を含むすべてのゲーム内効果音を抑止する。画面遷移後も選択を保持し、保存可能な環境では再起動後も保持する。

### 主要なデータ

- **BGM設定**: ランとは独立した音楽のON/OFF。既存音声設定から初回値を引き継ぐ。
- **効果音設定**: ランおよびBGM設定とは独立した効果音のON/OFF。既存音声設定から初回値を引き継ぐ。
- **表示状態**: 実際の全画面／通常表示と切り替え可否。
- **復帰先**: Settingsを開いた元の画面。
- **継続中のラン**: 資源、設備、王冠、転生、累計記録などの進行。タイトル復帰ではリセットしない。

## 成功基準

### 測定可能な成果

- **SC-001**: 対象5画面すべてで1回の操作でSettingsを開き、次の1回でBGM変更、効果音変更、全画面切り替え、またはタイトル復帰を実行できる。
- **SC-002**: BGMと効果音をそれぞれ10往復切り替え、4通りの組み合わせで画面を巡回しても、選択と表示・再生対象が毎回一致し、重複再生が0件である。保存可能な環境では再起動後も一致する。
- **SC-003**: 全画面対応環境で10往復切り替え、環境側からも解除した際、状態表示の不一致、主要操作部の欠落、入力位置のずれが0件である。
- **SC-004**: タイトル以外の対象4画面からタイトル復帰とCONTINUEを確認し、進行の消失、意図しない転生、収益の二重加算が0件である。
- **SC-005**: 各対象画面でSettingsを10回開閉し、背後の操作、二重遷移、閉じたSettingsへの入力が0件である。
- **SC-006**: 全画面非対応、要求失敗、保存不可の各条件でも、閉じる操作とタイトル復帰ができ、ゲームを操作不能にする事象が0件である。

## 前提と依存関係

- BGMは音楽、効果音は操作音やイベント音を指し、それぞれのON/OFFを独立させる。音量の段階調整は対象外とする。
- 画面内の表記は既存の英語に合わせ、ゲーム全体の翻訳は行わない。
- Settingsやタイトルの滞在による収益と経過時間は既存のルールに従い、新たな一時停止ルールを追加しない。
- タイトル復帰は進行を失わないため追加確認なしで実行する。NEW RUNや転生の既存確認は対象外とする。
- 全画面状態は起動中の実際の状態に追従する。次回起動時の自動全画面化や全画面選択の永続保存は対象外とする。
- ブラウザ版とデスクトップ版を対象とする。全画面の可否は環境に依存し、非対応時はFR-007に従う。
- 既存のセーブ、実績保持、一時プレイ、CONTINUEに依存し、既存の進行との互換性を維持する。
- Mキーの既存の音声一括切り替えはSettings表示中は無効とし、それ以外では、両方ONなら両方OFF、それ以外なら両方ONにする。実行結果はBGMと効果音の両方の選択・表示・保存に反映する。
