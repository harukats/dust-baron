# UI契約: Settings画面

## 入口と表示

対象はTitle、Game、Reign、Achievements、Victoryの5画面。
SOUND表記をSETTINGSに置き換え、どの画面からも1回で同じSettingsを開く。
固定1280×720上で既存のプレート・文字を使用する。

| 操作 | 表示 | 結果 |
| --- | --- | --- |
| BGM | BGM: ON / OFF | 音楽だけを切り替え、即反映・保存 |
| 効果音 | SFX: ON / OFF | 操作音・イベント音だけを切り替え、再生中の音もOFFで終了 |
| 全画面 | FULLSCREEN: ON / OFF / UNAVAILABLE | 実際の表示状態を示し、対応時だけ切り替え |
| タイトル復帰 | RETURN TO TITLE | 進行を保持してTitleへ移る |
| 閉じる | CLOSE | 同じ親画面へ戻る |

非対応表示と失敗メッセージはゲームの既存表記に合わせた英語にする。
全画面要求中はそのボタンのみ重複実行を防ぎ、CLOSEとRETURN TO TITLEは有効に保つ。
設定の変更だけでは新規ラン・転生・購入を実行しない。

## 入力とライフサイクル

- Settings中も親の更新、放置収益、イベント時間は既存ルールで進む。
- 親のクリック、Space、Enter、Q、M、Escapeを遮断する。
- Escapeは通常CLOSEと同じ。全画面解除で環境に消費された場合は解除を優先し、設定画面が残れば再度EscapeかCLOSEで閉じる。
- 閉じるイベントを背後へ渡さず、親を再作成せずに入力を復元する。
- Settings表示中に押していたキーのリピートで、閉じた直後に開始・採掘を実行しない。
- 親の終了・ゲーム破棄でSettingsとイベント購読を終了する。
- Settings外のMは両方ONなら両方OFF、それ以外は両方ONとし、選択を保存する。

## 全画面

ゲーム領域を対象にpointerupで標準全画面要求を出す。
成功を先取りせず、実際の状態でON/OFFを確定する。
拒否・例外時は変更失敗を表示して通常操作を継続する。
環境側解除と再表示でも現在の状態を取得する。全画面の好みを保存しない。
FITと縦横比を維持し、表示位置と入力位置を一致させる。

## タイトル復帰

現在の進行を精算し、保存可能なら保存する。追加確認は出さない。
Titleから開いた場合はSettingsだけ閉じる。それ以外は親とSettingsを終了し、Titleを開始する。
run.state、実績、所有モードを保持し、CONTINUEで再開できる。
一時プレイでも同じ起動中の継続を可能にする。保存できていない状態を保存成功として表示しない。
