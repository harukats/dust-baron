# データモデル: タイトル画面のバージョン表示

## 配布版のバージョン

| 項目 | 型・制約 | 関係 |
| --- | --- | --- |
| version | 空でない有効なバージョン文字列。接頭辞 `v` を除き40文字以内。接尾辞を保持する。 | 情報源は package.json の version。 |
| 表示文字列 | `v` + version。切り詰め・丸めなし。 | Title の Text 1つに表示。 |

番号は配布版に付随する不変の情報であり、プレイヤーの進行や保存データには属さない。再ビルドされた配布版は、その作成時の番号を表示する。

## 表示調整値

`TITLE_VERSION_UI` は右余白20、下余白16、文字サイズ16、色 COLOR.sub、最大幅480を保持する。ゲーム座標の調整値として config.ts に定義する。版番号を複製しない。文字サイズ16pxを維持し、Text 自体の均等縮小は行わない。最大幅480pxは対応範囲の画面確認に使う合格基準とする。

## 状態と寿命

タイトル作成 → Text を1つ生成 → 表示中は不変 → シーン終了で破棄。再表示時は同じ配布版の番号から1つ生成する。新しいセーブ項目、状態遷移、移行処理は不要。
