# 機能仕様書: タイトル画面のバージョン表示

**機能ブランチ**: 未作成（仕様作成時のブランチ: `main`）
**作成日**: 2026-10-03
**状態**: ドラフト
**入力**: 「タイトル画面の右下にpackage.jsonから取得できるバージョン番号を表示してほしい」

## ユーザーシナリオとテスト

### ユーザーストーリー 1 - 利用中のバージョンを確認する (優先度: P1)

プレイヤーはタイトル画面の右下を見て、利用中のゲームのバージョンを確認できる。更新の確認や不具合報告で正確なバージョンを伝えられる。

**優先度の理由**: 追加操作なしでバージョンを確認できることが本機能の目的である。

**独立したテスト**: タイトル画面を開き、右下の番号をその配布版のバージョンと照合する。

**受け入れシナリオ**:

1. **前提**: 配布版のバージョンが `0.2.1` である。**操作**: タイトル画面を開く。**結果**: 右下に `v0.2.1` が1つ表示され、追加操作なしで読める。
2. **前提**: `package.json` の `version` を変更した新しい配布版である。**操作**: タイトル画面を開く。**結果**: 表示用の番号を別途変更せず、新しいバージョンが表示される。
3. **前提**: バージョンにプレリリース表記やビルド識別子がある。**操作**: タイトル画面を開く。**結果**: 接尾辞を含む全文が表示される。
4. **前提**: 標準サイズまたは縮小表示のタイトル画面である。**操作**: 表示と既存操作部を確認する。**結果**: 番号はゲーム表示領域の右下に収まり、背景から判別でき、既存の文字や操作部と重ならない。
5. **前提**: バージョンが表示されている。**操作**: ゲーム開始と音声設定の既存操作を行う。**結果**: 各操作が従来どおり機能する。
6. **前提**: タイトル画面が再表示される。**操作**: 右下を確認する。**結果**: 同じバージョンが1つだけ表示される。

### エッジケース

- 接頭辞 `v` を除き40文字の番号でも、プレリリース表記やビルド識別子を含む全文を表示する。
- 横長・縦長のウィンドウでは、外側の余白ではなくゲーム表示領域の右下に配置する。
- タイトル画面の再表示で番号が重複しない。

## 要件

### 機能要件

- **FR-001**: タイトル画面の初回表示から、右下にバージョンを1つ表示する。
- **FR-002**: 番号の正は、その配布版を作成した際の `package.json` の `version` とし、表示用の番号を別途手動管理しない。
- **FR-003**: 表示は `v` にバージョン全文を続けた形式とし、接尾辞を省略しない。
- **FR-004**: ゲーム表示領域の右端・下端に余白を取り、拡大縮小後も全文が領域内の右下に収まる。
- **FR-005**: 背景から判別できる文字とし、既存の文字や操作部と重ならず、ゲーム開始と音声設定の入力を妨げない。
- **FR-006**: ブラウザ版とデスクトップ版で、各配布版のバージョンを同じ形式で表示する。
- **FR-007**: タイトル画面の再表示後も表示数は1つとする。

### 主要なデータ

- **配布版のバージョン**: 利用中のゲームを識別する文字列。プレリリース表記やビルド識別子も含める。

## 成功基準

### 測定可能な成果

- **SC-001**: タイトル画面で追加操作0回で利用中のバージョンを読み取れる。
- **SC-002**: 通常版とプレリリース版の確認で、表示番号が各配布版のバージョンと100%一致する。
- **SC-003**: 標準サイズと縮小表示の両方で、通常版・プレリリース版・40文字の境界値を全文判読でき、文字の欠け・既存文字や操作部との重なりが0件である。
- **SC-004**: ゲーム開始と音声設定の確認操作がすべて成功し、タイトル画面の再表示後も表示数が1つである。

## 前提と対象範囲

- `package.json` の `version` は有効なバージョン文字列であり、配布版の識別に用いる既存の情報である。対応範囲は接頭辞 `v` を除き40文字以内とし、41文字以上は対象外とする。
- 表示形式は `v` 接頭辞を採用する。書体・文字サイズ・色・余白は既存の画面に合わせ、計画段階で決める。
- 右下とは既存の固定比率で拡大縮小されるゲーム表示領域の右下を指す。
- 同じ受け入れシナリオをブラウザ版とデスクトップ版に適用する。
- 他画面への表示追加、更新通知、リリース履歴、コピー操作は対象外とする。
- セーブ形式、進行状態、収益計算、音声設定の保存方法は変更しない。
