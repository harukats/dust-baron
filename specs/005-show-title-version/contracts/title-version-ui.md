# UI 契約: タイトル画面のバージョン

- 情報源: 配布版の package.json の version。
- 表記: `v0.2.1`。プレリリース・ビルド識別子もそのまま続ける。
- 場所: 1280×720 のゲーム座標で右下 `(1260, 704)`、原点 `(1, 1)`。
- 外観: 既存 label の太字等幅フォント・暗い輪郭、16px、COLOR.sub。
- 対応範囲: 接頭辞 `v` を除き40文字以内。41文字以上は対象外。
- 幅: 最大480px。文字サイズ16pxを維持し、Text 自体の均等縮小は行わない。
- 可読性: 通常版・プレリリース版・40文字の境界値について、1280×720・960×540・720×960で全文を判読できることを確認する。
- 入力: 非インタラクティブ。クリック・Space・Enter の開始と音声操作を妨げない。
- 寿命: タイトルに1つ。再起動・再表示でも1つ。Game/Victory への表示追加は行わない。
- 一時プレイ: 左側の通知と重ならない。
- 配布: ブラウザとデスクトップで同じ契約を適用。読み込みの追加通信はない。

FR-001〜003 は表記と情報源、FR-004〜005 は配置と入力、FR-006 は配布、FR-007 は寿命で検証する。
